Camera Management

1
Klik "Add Camera"
Klik tombol biru Add Camera di pojok kanan atas, atau tombol + di sidebar kiri bawah.
2
Isi Nama Kamera
Masukkan nama lokasi kamera, misal Area Produksi atau Pintu Masuk Gudang.
3
Masukkan IP atau URL
Ketik IP kamera di kolom IP, lalu pilih brand (Hikvision/Dahua) agar URL RTSP terisi otomatis. Ganti password sesuai kamera.
4
Simpan & Monitor
Klik Save. Kamera langsung mulai streaming dan deteksi APD berjalan otomatis.
Format URL yang Didukung
Tipe KameraFormat URLKeterangan
Hikvision (RTSP) rtsp://admin:password@192.168.1.x:554/Streaming/Channels/101 Channel 101 = stream utama kamera 1. Ganti 201 untuk kamera 2.
Dahua (RTSP) rtsp://admin:password@192.168.1.x:554/cam/realmonitor?channel=1&subtype=0 subtype=0 = main stream (HD), subtype=1 = sub stream (ringan).
Generic RTSP rtsp://admin:password@192.168.1.x:554/stream Untuk kamera IP generik. Path /stream bisa berbeda per merk.
HTTP MJPEG http://192.168.1.x:8080/video Untuk kamera IP yang menggunakan MJPEG over HTTP.
DVR Xiongmai dvrip://admin:password@192.168.1.x:34567/0 Angka di akhir = nomor channel (0 = kamera 1, 1 = kamera 2).
File Video /path/ke/file/video.mp4 Untuk testing. Format: .mp4 .avi .mov .mkv. Video diulang terus.
Webcam Lokal 0 Angka 0 = webcam pertama di server. 1 = webcam kedua, dst.
Tips: Jika kamera berstatus Offline setelah ditambah, periksa: (1) IP kamera dapat di-ping dari server, (2) username & password benar, (3) port 554 tidak diblokir firewall. Coba ganti path stream jika gagal (misal /stream1, /live, /h264).
